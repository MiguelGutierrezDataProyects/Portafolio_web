# Portafolio — Miguel Gutierrez

Analytics Engineer & Data Analyst.
Sitio estático en HTML y CSS puro, publicado con GitHub Pages.

**En vivo:** https://miguelgutierrezdataproyects.github.io/Portafolio_web/

## Contenido

- **Análisis en Python** — cuatro casos de análisis exploratorio y diagnóstico sobre datos reales y públicos, más dos ejercicios de machine learning.
- **Tableros en Power BI** — cinco dashboards publicados: facturación y proyección, recursos humanos, estado de producto, seguridad vial y distribución de ventas.

## Estructura

```
index.html                    portada
proyectos_en_python.html      listado de proyectos en Python
proyectos_en_power_bi.html    listado de tableros en Power BI
css/                          normalize.css + style.css
js/contact.js                 formulario de contacto (Formspree)
images/                       recursos gráficos
projects/                     cada proyecto con su análisis
```

## Stack del sitio

HTML5, CSS3 (variables nativas, grid y flexbox), JavaScript sin dependencias.
